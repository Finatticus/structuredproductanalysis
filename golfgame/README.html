PART ONE一、遊玩方式與內容

快速開始

  1. 用手機瀏覽器打開網站（GitHub Pages 網址）。
  2. 加到主畫面：iPhone 用 Safari →「分享」→「加入主畫面」；Android 用 Chrome →「⋮」→「加到主畫面」。之後從主畫面圖示打開就是全螢幕，跟 APP 一樣。
  3. 第一次進來先「註冊新帳號」。註冊後帳號是停用（N）狀態，要等管理員 Michael 在遊戲裡的「管理」頁面打開（Y）才能登入。
  4. 登入一次之後會記住帳號，下次打開直接進大廳；要換帳號請按大廳右上「登出」。
  5. 建議橫向拿手機玩，畫面比較大；直向也可以玩。
第一次開遊戲會下載約 10MB 的寫實材質（草地、沙、岩石、真實天空），之後會存在手機裡，不用再下載。

大廳

單人回合
選球場、9 洞 / 18 洞、梯台、風、果嶺速度、OK 推距離、重打次數。打完成績會存到 Google 試算表，並獲得能力點。
建立遊戲間
你的手機當主機，畫面會出現 6 位數驗證碼，給朋友輸入就能一起打。可選比桿賽或比洞賽。
加入遊戲間
輸入朋友給的 6 位數驗證碼。
練習場
任選一洞反覆打，不計分。進洞會自動回到發球台，選單裡可以「回到發球台」或「換下一洞」。

下方分頁：紀錄（最近 40 回合）、角色（外觀與素質）、管理（只有 Michael 看得到）。

擊球操作

動作怎麼做
上桿（決定力道）按住畫面，往下拉 = 上桿，角色同步上桿。手指離按下的位置越遠力道越大；慢慢往上移只會把力道收小，不會擊球，可以慢慢上下調到想要的力道。
出桿（擊球）調好力道後，快速往上滑才會出桿擊球（比照真實揮桿要快速下桿）。力道鎖定在快速上滑開始前最低的那一點。放開手指或只是慢慢移動都不會擊球（等於取消）。
力道上限拉到底是 100%。再多拉一點可以到 110%（「超揮」），多一點距離但誤差會大很多（力量條變紅）。
曲球快速上滑那一段的方向決定曲球：直直往上 = 直球；偏右 = 右曲（Fade）；偏左 = 左曲（Draw）。偏 4° 以內都算直球，偏越多彎越多，最大約旋轉軸 ±20°。
手指軌跡擊球後畫面會留下手指軌跡約 2.5 秒：灰線 = 上桿、金色箭頭 = 出桿、白色虛線 = 正上方參考線，並標示「直球 / 左曲 / 右曲、偏幾度」，可以檢查自己是不是滑歪了。
瞄準預設自動瞄準（一開始都是直線）：開球對準球道中央「預估落點」，打得到果嶺時對準旗桿。調整方向的方式：
① 在畫面任何地方直接左右滑（一開始就往左右滑才算瞄準；靈敏度低，滑 20px 約轉 1°，推桿時更細）；② 按 ◀ ▶（按住會連續轉，每下 0.5°）；③ 點右上小地圖的任何位置，直接瞄那裡。
選桿系統會依距離、球位、高低差自動選桿。可以按球桿卡片左右的 ‹ › 換，或直接點下面的小標籤（1W、7I…）。
推桿球在果嶺上會自動換推桿，並顯示坡度格線（越紅越陡）。往下拉的長度 = 平地上會滾多遠（碼），HUD 顯示「推桿刻度」（拉到底的距離，依距旗自動選 3/5/8/10/12/15 碼，超過 15 碼才用 20/25 碼）與目前力道（例如 6.5 Y）。出桿一樣要快速上滑（推桿的速度門檻較低）。會顯示一段預測推桿線，長度由「讀果嶺」素質決定。
俯瞰 ⛶切換高空俯瞰，看清楚落點附近的障礙。再按一次回到第三人稱。
重打單人回合可以設定重打（Mulligan）次數，打完一桿後按「重打」回到擊球前。
快轉球在飛的時候點一下畫面 = 3 倍速。洞的開場鏡頭點一下可以跳過。

鏡頭流程

  1. 每洞開始：從果嶺上空飛回發球台（開場）。
  2. 準備擊球：第三人稱，鏡頭在角色斜後方，看得到自己的角色上桿、揮桿。
  3. 擊球瞬間：切到模擬器式的球後視角，接著追球鏡頭跟著球飛、落地、滾動。
  4. 推桿與 45 碼內短切：鏡頭留在後方，視線跟著球。

規則

  • 擊球順序：開球依上一洞成績（打得好的先，第一洞主機先）；之後一律離洞最遠的人先打。
  • 水障礙 / 峽谷：罰 1 桿，在球最後離開陸地的位置往後退 2 公尺以上，在不是障礙的地方抛球。
  • 出界 OB：罰 1 桿，回到原位重打（擊球距離與罰桿）。
  • OK 推（Gimme）：球停在果嶺上、離洞在設定距離內，自動算進洞，加 1 桿。
  • 撿球：一洞打到標準桿 2 倍還沒進，自動撿球，成績記為標準桿 2 倍（避免卡關）。
  • 比洞賽：每洞桿數少的人贏一洞，顯示「ALL SQUARE」或「某人 N UP」，18 洞打完結算。
  • 打完 9 洞得 1 能力點、18 洞得 2 能力點（練習場不算）。

記分卡記號

比照實體記分卡：圓圈 = 小鳥、雙圓圈 = 老鷹以上、方框 = 柏忌、雙方框 = 雙柏忌以上。

三座球場

每座 18 洞、Par 72，四組梯台：黑（100%）、藍（94%）、白（88%）、紅（78%）。果嶺直徑約 26~30 碼（比照台灣球場），坡度大多 1~3%。果嶺速度在回合設定裡可以用數字調整（Stimp 6.0~13.0，每次 0.5；台灣一般球場約 8）。

角色外觀

角色頁可以選男 / 女體型、膚色、髮色、上衣、褲子、帽子顏色，左邊會即時預覽並每 6 秒示範一次揮桿。

雙人連線

  1. 主機：大廳 →「建立遊戲間」→ 設定好 →「建立遊戲間」，畫面出現 6 位數驗證碼（10 分鐘內使用比較保險，最長保留 6 小時）。
  2. 朋友：大廳 →「加入遊戲間」→ 輸入驗證碼。
  3. 主機看到朋友「已就緒」後按「開始回合」。
  • 主機的裝置是伺服器：所有物理計算都在主機算，再把結果傳給朋友，所以兩邊看到的完全一樣。
  • 連線方式顯示「直連（WebRTC）」= 兩支手機直接傳資料，最快；顯示「GAS 轉送」= 網路擋住直連（常見於某些電信 4G/5G），改由 Google 試算表伺服器轉送，每次動作會慢約 1~2 秒，但因為高爾夫是輪流打，一樣可以玩。
  • 輪到對方時，你會看到對方的角色瞄準、上桿（直連時即時同步）。
  • 兩人各自的成績會存到各自的玩家工作頁。雙人回合不能重打。

PART TWO二、程式邏輯、公式與機率

部署步驟

1. Google Apps Script 後端

  1. 建立一個新的 Google 試算表。
  2. 選單「擴充功能」→「Apps Script」，把 gas/Code.gs 的內容全部貼上，存檔。
  3. 上方函式選 setup → 執行（第一次會要求授權，按允許）。會建立「Account」工作頁和 Michael 帳號（密碼 1220、啟用 Y）。
  4. 右上「部署」→「新增部署作業」→ 類型選「網頁應用程式」，執行身分「我」，存取權「所有人」→ 部署 → 複製「網頁應用程式網址」（結尾是 /exec）。
  5. 把網址貼到 js/config.js 的 GAS_URL: '' 引號裡；或打開遊戲登入畫面右上角 ⚙ 設定貼上（只存在那台裝置）。建議貼在 config.js，大家都會用到。
  6. 之後改了 Code.gs，要「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」才會生效（網址不變）。
測試用：在瀏覽器把設定的 GAS 網址填成 local，就會強制使用本機模式，不會動到正式的試算表。

2. GitHub Pages 網站

  1. 在 GitHub 建立一個 repository，把整個資料夾的檔案上傳（index.html、css/、js/、assets/、manifest.webmanifest、sw.js、README.html；gas/ 可以一起放，但它不會在網站上執行；style-sample.html、.claude/ 可以不傳）。
  2. repository 的 Settings → Pages → Source 選「Deploy from a branch」，分支選 main、資料夾選 /(root) → Save。
  3. 約 1 分鐘後網址會出現（https://帳號.github.io/repo名稱/）。
  4. 更新程式後，把 sw.js 第一行的 VERSION 數字加 1，手機重新打開兩次就會拿到新版。
本機模式：GAS_URL 留空時，帳號、成績存在那台裝置的瀏覽器裡（預設有 Michael / 1220），方便測試。本機模式下的遊戲間只能在同一台電腦開兩個分頁互連。

API（POST JSON，Content-Type 為 text/plain 以避開 CORS 預檢）

每個請求都帶 user、pass 驗證（帳號必須是 Y）。動作：register、login、getProfile、saveProfile、saveRound、getRounds；管理員：listAccounts、setActive、grantPoints、grantRespecs；遊戲間：createRoom、getRoom、joinRoom、updateRoom、sendMsg、getMsgs、closeRoom。

防作弊（簡單版）：saveProfile 時伺服器只允許能力點、重新分配次數往下減；只有在重新分配次數減少時，能力點才能退回到「累計獲得點數」。能力點只能由打完回合或管理員增加。

遊戲間資料（驗證碼、WebRTC 連線資料、轉送訊息）放在 GAS 的 CacheService，6 小時自動消失，不會在試算表留下垃圾。

物理引擎（js/physics.js）

空氣密度

P = 101325 × (1 − 2.25577×10⁻⁵ × 海拔)^5.25588 (Pa) ρ = P / (287.05 × (氣溫 + 273.15)) (kg/m³) 例：楓林谷 220m 22°C → ρ ≈ 1.17；赤岩峽谷 1600m 29°C → ρ ≈ 0.98（球飛更遠）

飛行（每秒 240 步數值積分）

球：半徑 r = 0.021335 m、質量 m = 0.04593 kg、截面積 A = πr² 相對風速 v_rel = v − 風(高度) 旋轉參數 S = r·ω / |v_rel| 阻力係數 Cd = 0.215 + 0.30·S 升力係數 Cl = min(0.34, 1.8·S − 1.5·S²) 加速度 a = g + (½ρA|v|/m)·(−Cd·v_rel + Cl·|v_rel|·L̂) L̂ = 旋轉軸 × v_rel（單位向量） 旋轉衰減 ω(t) = ω₀·e^(−t/25s)

係數是用 PGA Tour TrackMan 平均數據回歸出來的：Driver 167 mph / 10.9° / 2686 rpm → 模擬 Carry 271.6 碼（實際 275）；7 號鐵 120 mph / 16.3° / 7097 rpm → 170.6 碼（實際 172）。

風

顯示風速 = 10 公尺高度的風 實際風(h) = 風₁₀ × clamp( ln(h/0.05) / ln(10/0.05), 0.3, 1.25 ) （對數風廓線：離地越高風越大） 每一桿陣風：風 × (1 + N(0, 0.12))

旋轉軸與曲球

純後旋時旋轉軸水平朝右；旋轉軸傾斜 θ 度產生側旋，θ > 0 往右彎（Fade/Slice），θ < 0 往左彎（Draw/Hook）。

滾動與果嶺速度

Stimp 定義：球以 1.83 m/s 滾出，在平地滾 Stimp 呎停下 果嶺 crr = 1.83² / (2 × Stimp × 0.3048) / 9.81 （Stimp 11 → crr ≈ 0.051） 滾動加速度 = 重力沿坡面分量 g·n_y·(n_x, n_z) − crr·g·(速度方向) 停止條件：速度 < 0.03 m/s 且坡度推力 < 1.3·crr·g（靜摩擦比滾動阻力大 30%） 例：Stimp 8 → crr ≈ 0.070；果嶺最大坡度約 3.3%，所以球一定會停，不會一路滑走

進洞

  • 洞杯半徑 5.4 cm。球心經過洞杯範圍且速度 < 1.35 m/s → 進洞。
  • 太快但經過洞杯中心 70% 範圍內 → 擦邊（Lip-out）：方向隨機偏轉 ±40°、速度 × 0.6。
  • 空中直接飛進（水平速度 < 3 m/s）也算。

樹

每棵樹的樹冠是一顆碰撞球、樹幹是細柱。球穿過樹冠：速度 × (0.25~0.5 隨機)、方向隨機偏 ±63°、後旋 × 0.3、往下掉。灌木（林克斯）是一個圓柱範圍。

擊球參數與機率（makeLaunch）

所有隨機都是常態分布 N(0, σ)，亂數種子由「回合種子 + 洞 + 第幾桿 + 玩家」決定（可重現，主機算一次傳給客人）。

全揮桿

桿頭速度 = (82 + 0.36 × 力量) × 球桿比例 × 力道係數 力道係數 = 力道（0~1）；超揮 1.0~1.1 時 = 1 + (力道−1)×0.5，且所有誤差 × (1 + (力道−1)×8) 力道浮動 = 1 + N(0, σ力道) σ力道 = 0.06 − 0.00045×穩定度（55 碼內挖起桿改用切球 σ） 打偏程度 mis = |N(0, σ打偏)| × 球位誤差倍率 σ打偏 = 0.06 − 0.0004×擊球效率 擊球效率 = 球桿 smash × (0.96 + 0.0008×擊球效率) × (1 − 1.6×mis) 球速 = 桿頭速度 × 力道浮動 × 擊球效率 × 球位保留 發射角 = 球桿發射角 × (0.85 + 0.15×力道) + 球位加成 + N(0, 2.0 − 0.014×彈道控制) 後旋 = 球桿後旋 × (桿頭速度 / (113 × 球桿比例)) × (0.6 + 0.4×力道) × 球位旋轉倍率 （8 號鐵以下 × (0.85 + 0.003×旋轉控制)；打偏時 × (1 ± 2.5×mis)） 桿面誤差 = N(0, 3.0 − 0.022×準度) × 球位誤差倍率 × 抗壓倍率 想打的旋轉軸 = 推的方向 × 20°（−1~1） 實際彎曲 = 想打的 × (1 + N(0, 0.5 − 0.0042×曲球控制)) 旋轉軸 = 實際彎曲 + 2.0 × 桿面誤差 起飛方向 = 瞄準 + 0.75 × 桿面誤差 − 0.36 × 實際彎曲 （曲球會先往反方向開出去再彎回來）

推桿

平地滾動距離 D = 力道 × 推桿刻度（3/5/8/10/12/15/20/25 碼，自動選 ≥ 距離×1.2 + 上坡×8 的最小值） 初速 v₀ = √(2 × crr × g × D) × (1 + N(0, 0.06 − 0.0004×距離感) × 抗壓倍率) 方向 = 瞄準 + 出桿方向×1.5° + N(0, 1.0 − 0.007×推桿方向) × 抗壓倍率 在果嶺邊推桿：crr × 1.6

預測推桿線：用「距離感、方向、抗壓都是 99」的無誤差模擬跑一次，只畫出前 (1 + 0.08×讀果嶺) 公尺。推桿預設瞄準洞口，不幫你讀線。

抗壓（關鍵球）

以下情況所有誤差 × max(1, 1.6 − 0.009×抗壓)：在果嶺上推「Par 或更好」、第 16~18 洞、比洞賽。

自動選桿 / 預設瞄準 / 距離表

  • 距離表：每回合開始，用你的素質、無誤差、無風、該球場空氣密度，在平坦球道上模擬每支桿 100% 的 Carry 與 Total。
  • 自動選桿：需要距離 = 距旗 + 高低差 × 0.9，選「Carry × 球位保留 ≥ 需要距離 − 3m」裡最短的桿；開球且 Par 4/5 選一號木；果嶺上推桿；55 碼內沙坑選 SW。
  • 預設瞄準：打得到旗桿就瞄旗桿；打不到就瞄球道中心線上「預估總距離」的位置。

球場生成（js/terrain.js）

  1. 中心線：依碼數與狗腿角度畫出折線（Par 4 在 200~255m 轉彎、Par 5 兩個轉角），用 ±18m 移動平均平滑。
  2. 球道：沿中心線，寬度 = 球場基準寬（鷺灣 44m、楓林 32m、赤岩 34m）× (1 ± 雜訊)；有 tr 特徵的洞 × 0.85。
  3. 果嶺：橢圓（半徑 10.5~13.5m，直徑約 26~30 碼）加波浪邊緣；坡度 = 後高前低 0.8~1.8% + 左右 ±0.7% + 1~2 個高斯起伏（±0.05~0.12m）；整體墊高 0.55m。果嶺與果嶺邊不受旁邊沙坑、水池的高度影響。實測 54 洞果嶺坡度中位數 1.4%、最大 3.3%。
  4. 沙坑：果嶺周圍依 b0~b4 數量環繞；Par 4/5 在落點區（215~265m、Par 5 另有 380~440m）加球道沙坑；林克斯是小而深的壺型（深 1.5m）。
  5. 水 / 峽谷：wl/wr 落點區旁的池塘、wc 果嶺前、xc 橫越（溪流寬 7m、峽谷寬 26m 深 26m）、sl/sr 一整側是海。赤岩峽谷的水都換成峽谷。
  6. 高度：起點到果嶺的高低差（UP/DN ±14m、up/dn ±6m）+ 大尺度雜訊 + 小起伏（球道上壓平 80%）+ 走廊外地形抬升（峽谷是平頂台地與岩壁）。
  7. 樹：在長草外圍隨機撒點，越靠近走廊邊越密（形成樹牆），彼此保持距離；遠景另外撒一圈只畫不碰撞的樹。
  8. 旗桿：每回合依種子在果嶺上試 10 個位置，選坡度最小的。
  9. 地面種類優先順序：界外 → 海 → 水/峽谷 → 果嶺 → 沙坑 → 果嶺邊 → 發球台 → 球道 → 海灘荒地 → 長草 → 深草/荒地。

同一個種子在任何裝置都生成完全一樣的洞，所以雙人時只需要傳種子。

連線協定（js/net.js）

  1. 主機建立 WebRTC 連線、等候選位址收集完成（最多 3.5 秒），把 offer 存到 GAS createRoom，拿到 6 位數驗證碼。
  2. 客人用驗證碼 getRoom 取得 offer，產生 answer，joinRoom 存回去。主機每 2 秒輪詢，拿到 answer 就完成直連。STUN：Google 公用伺服器。
  3. 12 秒內沒直連成功 → 改用 GAS 轉送（sendMsg / getMsgs，每 1.5 秒輪詢）。直連成功後仍每 6 秒輪詢一次當備援。每則訊息有唯一 id，重複的會丟掉。
  4. 訊息：hello（交換玩家素質與外觀）、start（回合設定與種子）、swing（客人 → 主機：力道、曲球、瞄準、球桿）、shot（主機 → 客人：擊球參數與 30fps 軌跡）、state（主機 → 客人：所有球位、桿數、輪到誰）、aim（瞄準預覽，只走直連）、toast、next（下一洞）、leave。

畫面（js/render.js、js/character.js）

  • Three.js r160、ACES 色調映射、PCF 柔和陰影（陰影範圍跟著球或角色移動）。
  • 天空與環境光：Poly Haven 的真實全景天空 HDR（kloofendal_48d_partly_cloudy_puresky，CC0）。
  • 地形材質：先依地面種類畫一張顏色圖（約每像素 0.3m，含割草條紋、果嶺棋盤紋、果嶺邊），再在著色器裡疊上 Poly Haven 照片材質的明暗細節（草地 leafy_grass、沙 coast_sand_01、岩石 rock_face_03，都是 CC0）與法線貼圖；越遠細節越淡；赤岩峽谷的陡坡自動換成三平面投影的岩石材質。
  • 水面：反射天空的低粗糙度材質 + 程式產生的漣漪法線貼圖並持續流動。
  • 樹：多顆凹凸球合併成樹冠（闊葉、楓樹）、多層錐體（松樹）、杜松、仙人掌、岩石，全部用 Instancing 一次畫出。
  • 球：遠處自動放大維持可見、地面投影圓點、金色彈道線（面向鏡頭的帶狀網格）。
  • 內建角色：膠囊體組成，外觀可換色；揮桿用「手臂平面 + 球桿平面」關鍵影格，手臂和腿用兩段式 IK 求解，所以雙手永遠握在桿上、腳不會滑；下桿時球桿比手慢（延遲釋放）。
  • 音效：WebAudio 即時合成（擊球、落地、樹葉、落水、進洞），不需要音效檔。
  • 畫質設定（高/中/低）調整解析度倍率、陰影大小、地形網格密度、樹木數量。
  • 橫向寬螢幕時水平視角限制在約 72°（直向 62° 垂直視角），避免畫面邊緣的人物和樹被拉寬；鏡頭距離會依視角自動調整。每幀檢查畫面大小，手機轉向也會即時修正比例。

⚠ Mixamo 寫實角色接口（重點）

提醒自己

要換寫實角色時，跟 Claude 說「我要改用 Mixamo 角色」

大致流程（Claude 會帶你做）：

  1. 到 mixamo.com 用 Adobe 帳號登入（免費）。
  2. 挑一個寫實角色，下載成 FBX → 存成 assets/character/model.fbx。
  3. 搜尋動作「Golf Drive」「Golf Putt」「Idle」（下載時選 Without Skin），存成 drive.fbx、putt.fbx、idle.fbx 放同一個資料夾。
  4. 把 js/config.js 裡 CHARACTER.mode 從 'procedural' 改成 'mixamo'。
  5. 可能需要微調：topFraction（上桿頂點在動作中的比例）、impactFraction（擊球瞬間比例）、ballDistance（站位距離）、clubRotation（球桿在手上的角度）。

程式端已完成：js/character.js 的 MixamoGolfer 類別會載入 FBX、用 AnimationMixer 播放，上桿時把揮桿動作停在對應時間點，放開後播完並在擊球瞬間觸發擊球；球桿綁在右手骨頭（mixamorigRightHand）。載入失敗會自動退回內建角色。
