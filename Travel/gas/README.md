# 雲端設定（Google Apps Script）

網站的資料全部存在你自己的 Google 帳號：

- 旅程內容 → Google 試算表（`trips` 工作表）
- 圖片 → Google Drive「TravelAtlas Images」資料夾
- 外部圖片搬移紀錄 → 試算表（`images` 工作表）

## 更新程式（已經部署過的人）

1. 打開試算表 → **擴充功能 → Apps Script**。
2. 把 `Code.gs` 整份貼上取代（檔案裡已經是你的管理者密碼 `TOKEN`；訪客密碼改在網站的「設定 → 訪客密碼」管理）。
3. **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**。網址不會變。
4. 這次新增了「下載外部圖片」功能，Google 會要求重新授權（連線到外部網站），按允許即可。

## 第一次部署

1. 到 [Google 試算表](https://sheets.new) 新增一份空白試算表。
2. **擴充功能 → Apps Script**，貼上 `Code.gs`。
3. 修改 `TOKEN`（管理者密碼）。訪客密碼部署後在網站「設定 → 訪客密碼」新增或刪除。
4. **部署 → 新增部署作業 → 網頁應用程式**；執行身分「我」、存取權「所有人」。
5. 複製網頁應用程式網址，貼到 `js/config.js` 的 `gasUrl`。

> 「所有人」是指網站能呼叫它；沒有密碼的人什麼都讀不到。

## ⚠ 這個資料夾不要公開

`Code.gs` 裡有密碼。把網站放上 GitHub Pages 等公開空間時，只上傳 `site` 資料夾，不要上傳 `gas`。
