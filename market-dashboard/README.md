## 一、部署 GAS 後端

1. 新建一份 Google 試算表 → 選單「擴充功能 → Apps Script」。
2. 把 `Code.gs` 全部內容貼上，覆蓋預設程式碼；再按左側「檔案 ＋ → 指令碼」新增一個名為 `Macro` 的檔案，貼上 `Macro.gs`。兩個檔案都要存檔。
3. 上方函式選單選 `testQuotes` → 執行，第一次會要求授權（試算表、外部連線），允許後在「執行紀錄」看到報價 JSON 即代表正常。
4. 右上「部署 → 新增部署作業」→ 類型選「網頁應用程式」
   - 執行身分：**我**
   - 存取權：**所有人**
5. 複製產生的網址（`https://script.google.com/macros/s/……/exec`）。

> 之後修改 Code.gs，要到「部署 → 管理部署作業 → 編輯 → 版本選『新版本』」才會生效，網址不變。

## 二、設定前端

二擇一：
- 把網址貼到 `app.js` 第 6 行 `const API_URL = '';`
- 或打開網頁後，在登入頁下方「後端網址設定」貼上並儲存（存在瀏覽器）。

直接雙擊 `index.html` 即可使用；也可以放到 GitHub Pages / Netlify 等靜態空間。

## 三、試算表結構

- **Account** 工作頁：A 帳號｜B 密碼｜C 建立時間｜D 審核狀態
  - D 欄：空白＝待審核、「通過」、「拒絕」、「停用」。只有「通過」的帳號與管理員（`michael`，在 Code.gs 的 `ADMIN_ACCOUNT` 設定）可以登入。
  - 管理員在網頁「⚙ 設定 → 帳號審核」操作，或直接在 D 欄填「通過」（最慢 5 分鐘生效）。一般帳號的個人工作頁在審核通過、第一次登入時才建立。
  - B 欄存的是「隨機鹽 + SHA-256 雜湊」，不是明碼（即使試算表外流也無法得知原密碼）。
- **<帳號名稱>** 工作頁（註冊時自動建立）：
  - A:E 監控清單：類別｜代碼｜顯示名稱｜資料來源｜新增時間（列的順序 = 畫面上的順序）
  - G:H 個人設定：設定項目｜值（例如 `cardOrder` = 區塊排列順序）
  - 可直接在試算表編輯顯示名稱、調整列順序，重新整理網頁即生效。刪除標的時請只清除 A:E 該列內容或用網頁刪除，不要刪整列（會動到 G:H 設定）。

## 四、報價來源

| 區塊 | 來源 | 更新方式 | 備註 |
|---|---|---|---|
| 匯率 | Yahoo Finance | GAS 代抓，前端每 5–60 秒輪詢 | 外匯 24 小時報價 |
| 台股（上市/上櫃） | 證交所 MIS 即時行情 | 同上 | 盤中即時，約 5 秒一筆 |
| 台股（興櫃，如 3595） | Yahoo Finance (`.TWO`) | 同上 | MIS 不含興櫃，自動切換 |
| 國外股票 | Yahoo Finance | 同上 | 美股即時；日股等可能延遲約 20 分鐘 |
| 指數 / 商品 | Yahoo Finance | 同上 | 期貨（黃金 GC=F、原油 CL=F）可能延遲約 10 分鐘 |
| 虛擬貨幣 | Binance WebSocket | 瀏覽器直連，逐筆推播 | TSMUSDT / NVDAUSDT 為 Binance U 本位永續合約；斷線自動改 REST 輪詢並重連 |

休市時來源會回傳最後成交價，畫面就停在最後價格；連線失敗時也保留上一次報價。

### 配額注意
GAS 免費帳號 UrlFetch（向外部網站抓資料）每日上限 **20,000 次**（Workspace 帳號 100,000 次）。市場監控頁上方的「今日 API 呼叫」會即時顯示今天已用次數（所有使用者、分頁合計，台北時間每日歸零），用量達 70% 變黃、90% 變紅。

預設更新頻率為 **30 秒**（可在畫面右上自行調整，選擇會記在瀏覽器）。單人、預設清單估算：

| 更新頻率 | 每天開 8 小時 | 24 小時都開 |
|---|---|---|
| 30 秒 | 約 2,100 次 | 約 6,200 次 |
| 10 秒 | 約 6,000 次 | 約 17,800 次 |

虛擬貨幣直連 Binance 不佔額度。只有停留在市場監控頁、且分頁在前景時才更新；切到其他頁或背景會完全停止。每個區塊可按 ⏸ 停止更新，工具列「⏸ 全部停止」一次停止全部（設定存在帳號 `pausedCats`）。多分頁/多裝置同時開會倍增用量。

## 六、走勢圖與編輯

- **當日走勢小圖**：每列價格左側。台股/國外/指數/匯率為當日 5 分線（後端快取 2 分鐘、每 3 分鐘更新）、虛擬貨幣為近 24 小時 15 分線；虛線為昨收（基準），尾端會接上即時價格。
- **點任一標的開啟走勢圖**：
  - 週期：日 / 週 / 月；範圍：3月 / 6月 / 1年 / 3年（預設）/ 全部
  - 圖型：K 線 / 折線；成交量可開關（匯率等無成交量的標的會自動停用）
  - 滑鼠滾輪縮放、按住拖曳左右移動；手機雙指縮放。後端多抓了更早的歷史，往左拖可看超過 3 年
  - 「📈 技術分析」：SMA5/10/20/60/120 疊在主圖，KD(9,3,3)、MACD(12,26,9) 各一個副圖，每項都可勾選開關；副圖之間的分隔線可上下拖曳調整高度
  - 圖表設定會記在瀏覽器，下次打開沿用
- **✎ 編輯**（工具列）：拖曳標的調整順序、拖曳區塊標題（⠿）移動整個區塊、按紅色 × 刪除；排序會存回試算表，換電腦登入也一樣。

> 更新 Code.gs 後記得「管理部署作業 → 編輯 → 版本：新版本 → 部署」，否則新功能（走勢、排序）會出現「未知的 action」錯誤。

**編輯版面**：按「✎ 編輯版面」後可拖曳字卡標題調整順序、設定每張字卡寬度（1/3～全寬）、取消「顯示」隱藏字卡（隱藏的不抓資料，省額度）；版面存在試算表個人設定 `macroLayout`，換電腦也一樣。「還原預設」可回到原始排列。

每次開啟約用 35–45 次外部請求（台股類股的歷史收盤每天第一次較多），快取期間內重開幾乎不耗額度。

注意：
- FOMC 機率由期貨價格推算，與 CME FedWatch 網站可能有些微差異（期限溢酬、資料時間不同）。
- 證交所信用交易與法人資料於交易日晚間公布，盤中看到的是前一交易日。
- 上櫃資料：櫃買中心沒有歷史區間查詢，只能逐日抓。後端會把查過的日子永久存在 Apps Script 的「指令碼屬性」，之後只補新日期。第一次切到上櫃約抓 25 個交易日（信用交易約 20 秒），之後每次開啟再補 25 天，信用交易幾次後補滿 120 個交易日、法人 30 個交易日；補滿後每次只檢查最近幾天（約 4–5 次請求）。
- 上市資料先用 FinMind（一次取得半年），失敗時改用證交所逐日查詢並永久保存（第一次約 17–20 個交易日，之後逐次補齊），面板下方的「來源」會寫出原因。建議到 finmindtrade.com 免費註冊，把 token 貼到 Macro.gs 的 `FINMIND_TOKEN`，成功率會高很多。
- FinMind 免費 API 有每小時次數限制，若 Google 伺服器 IP 被限流，會自動改用證交所（只顯示最新一日）。

## 八、個股研究

輸入台股代號（2330）、美股代號（NVDA），或其他市場（7011 JP、0700 HK），顯示完整檔案：
走勢與成交量（K 線、MA20/60/120/240）、技術分析（RSI、KD、MACD、乖離）、歷史波動度（HV20/HV60 與百分位）、
估值（本益比在自身歷史的百分位帶）、成長與獲利（單季 EPS、營收年增、毛利率／營益率／淨利率）、月營收（台股）、
籌碼（台股：法人、外資持股、融資；美股：機構持股、放空比例）、相對強弱（對加權指數／S&P 500）、分析師目標價與評等、股利、公司簡介。

每個面向依固定規則給出判斷（多頭／空頭、偏高／偏低、成長／衰退…），判斷依據寫在各字卡下方；各面向彼此獨立、不加總成買賣建議。
資料：台股 FinMind（需 Macro.gs 的 token）＋證交所＋Yahoo；美股與其他市場 Yahoo Finance。

## 九、選股篩選器（需先啟用一次）

1. 在 Apps Script 新增指令碼檔 `Research`、`Screener`，貼上對應的 .gs 內容並重新部署。
2. 在編輯器上方函式選單選 **setupScreener** → 執行（會要求「管理觸發條件」等授權）。
3. 後端會開始每 5 分鐘補一段歷史（上市＋上櫃約 2,300 檔、250 個交易日），約 20–40 分鐘完成後自動停止；之後每天 21:40 自動抓當日資料並重算。
   資料存在試算表隱藏工作頁 `_daily`（每日快照）與 `_screen`（算好的篩選表），請勿手動修改。

篩選條件共 60 多項，分為：基本條件、價值（本益比／淨值比／殖利率）、成長（月營收年增／月增／累計）、均線與趨勢、價量與突破（量比、創 N 日新高、各期間漲跌幅）、
技術指標（RSI、KD、MACD、波動度）、籌碼（外資／投信連買連賣天數、1／5／20 日買賣超、土洋同買、融資增減、券資比）。
內建 9 組常用條件按鈕，也可以把自己的條件「★ 存為常用」（存在帳號設定）。結果表可點欄位排序、點代號開啟個股研究、一鍵加入自選。
