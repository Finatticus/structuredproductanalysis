# 市場日報｜盤後午報：分析方向與報告標準

這份是**盤後午報**的規則。每次產出或修改午報前都要從頭到尾讀完。
網站共用的版面、class、寫作標準（特別是 6.1 摘要、6.2 分析與歸納）以 `daily/RULES.md` 為準；本檔只寫午報不同的地方。

---

## 一、定位

- **讀者在台股收盤後、下午看。** 要回答三個問題：今天台股發生了什麼、為什麼、明天和這週要注意什麼。
- **聚焦台股。** 其他市場只寫重大的、會影響台股或台美市場的事。
- **比早報精簡，但不能只丟資訊。** 每一段都要有歸納和判斷。
- **和早報接續。** 午報要對照當天早報的台灣觀點：今天的走勢驗證了什麼、推翻了什麼，短期觀點要不要調整。

## 二、時間界線與資料範圍

- **時間界線：當天台北 15:30。** 只用 15:30 以前公開的資訊。
- **新聞窗口：當天台北 07:00 到 15:30。** 不和當天早報重複；早報已寫過的事件，只寫新的發展。
- 15:30 時可以用的資料（以官方實際公布時間為準，查核時要確認）：
  - 加權、櫃買、類股指數、漲跌家數、個股收盤（13:30 收盤後）
  - 台指期日盤收盤與結算價（13:45 收盤後）
  - 三大法人買賣金額、三大法人期貨未平倉、選擇權 P/C 比（通常 15:00 前後公布）
  - 日股、韓股收盤（14:30）、A 股收盤（15:00）
  - 當天 07:00–15:30 的新聞、官員發言、數據
- 15:30 時**通常還沒有**的資料：外資個股買賣超明細（約 16:00 後）、融資融券（晚間）、新台幣收盤（16:00）、港股收盤（16:00）、歐美盤勢。這些不寫；需要時寫「盤中」數字並註明時間，或留給隔天早報。
- 只在週一到週五出報告。台股休市日不出午報。

## 三、作業流程

1. 讀本檔與 `daily/RULES.md` 的第五、六節；讀當天早報、`daily/state/view-log.md`、最近一份午報（沿用版型）。
2. 蒐集（可開 2 個子代理平行）：
   - **台股**：證交所 FMTQIK、MI_INDEX（類股、漲跌家數）、BFI82U（三大法人）、各權值股收盤；期交所行情、三大法人期貨、P/C 比；當天官員與主管機關發言；投顧與法人觀點。加權均線用 FMTQIK 自己算（含今天收盤）。
   - **新聞**：07:00–15:30 的重點新聞，每則確認發布時間；台股最多，其他市場只收重大事件。
3. 分析（見第四節）並寫報告（見第五節）。
4. **查核（必做）：**開獨立的查核子代理，核對所有數字、15:30 時間界線（包括每項官方資料在 15:30 是否已公布）、新聞窗口與內容、計算。修正後才發布。
5. 更新 `daily/reports.js`（最前面加一筆 `kind: "pm"`）、`daily/state/view-log.md`（在當天早報那一節下面加「午報更新」小節：台股短期觀點是否調整、關鍵價位、明天開盤要看什麼）。
6. 發布：同早報（`git add daily` → commit → `git pull --rebase` → push），檔名 `reports/YYYY-MM-DD-pm.html`，推送後確認網址回應 200。
7. 回報 5 行以內。

## 四、分析方向

### 4.1 盤勢歸納

- 用一句話定性今天：例如「恐慌性下殺」「技術性反彈」「量縮整理」「權值股撐盤、中小型股弱」。
- 拆解漲跌來源：台積電與前五大權值股貢獻多少點；電子與非電子、大型與中小型的差異。
- 看型態與量：開高走低或開低走高、收在高低點的位置、成交量和前幾天比。
- 族群輪動：哪些族群逆勢、哪些重挫，背後原因是同一件事還是不同事件。

### 4.2 籌碼解讀

- 外資、投信、自營商（區分自行買賣與避險）的方向和規模，和前幾天比。
- 外資台指期淨未平倉的變化；遇到結算週要特別分析轉倉與結算價。
- 選擇權 P/C 比的變化，代表支撐或壓力是否增加。
- 歸納：今天的賣壓或買盤主要來自誰？是恐慌、去槓桿、避險，還是看法轉變？

### 4.3 技術面與關鍵價位

- 自算均線（5、10、20、60、120、240 日），寫出今天站上或跌破了哪一條。
- 缺口、前波高低點、整數關卡。
- 列出明天的壓力與支撐，每個都寫理由。

### 4.4 消息面與政策

- 當天官員、央行、金管會、國安基金相關發言，寫出市場可能的解讀。
- 重要公司消息、法說、營收。

### 4.5 觀點更新（午報的核心）

- 對照當天早報的台股短期觀點：維持、上修或下修，寫出原因。
- 更新短期情境表與機率（主觀，加總 100%）。中長期觀點原則上留給早報，除非今天發生改變中長期判斷的事件。
- **明天開盤要看什麼**：今晚美股與費半、台積電 ADR、台指期夜盤、重要數據與事件（台北時間），各自偏多或偏空的情境。

### 4.6 其他市場（簡要）

- 日股、韓股、A 股收盤與主要原因，一兩句即可。
- 重大事件不限國家（地緣、政策、重大企業消息），寫對台股的含意。

## 五、版面

檔案 `daily/reports/YYYY-MM-DD-pm.html`，`<body data-report="YYYY-MM-DD-pm">`，共用 `../assets/report.css`、`../assets/report.js`、`../reports.js`。刊頭標「盤後午報」與「資料截至台北 15:30」。

主分頁（固定順序與 id）：

| id | 名稱 | 內容 |
| --- | --- | --- |
| `pm-overview` | 總覽 | 詳細摘要（一句定性＋ 5–7 條）、今日數據列、觀點更新一行（短期立場與較早報的變化）、明天要看的三件事 |
| `pm-theme` | 專題（選用） | 當天有值得深挖的事件才放（例如單日重挫的性質判斷、重大政策、權值股法說）。格式同早報 5.5：專題摘要、`div.essay` 深入分析（4–6 段）、市場怎麼看 vs 我怎麼看、證據表、觀察清單。沒有適合的題目就不放，不要硬湊 |
| `pm-tw` | 台股盤後 | 子分頁：`pm-mkt` 盤勢（指數、類股、權值股、歸納）、`pm-chips` 籌碼（法人、期貨、選擇權、歸納）、`pm-tech` 技術與價位、`pm-policy` 消息與政策 |
| `pm-view` | 觀點更新 | 摘要；與早報的對照；短期情境表；明天開盤要看什麼（表格：時間、事件、偏多情境、偏空情境） |
| `pm-other` | 其他市場 | 日韓中收盤小表＋重大事件，每項寫對台股的含意 |
| `pm-news` | 新聞 | 07:00–15:30 的新聞，可展開卡片（同早報 5.8 格式），篩選：全部／台灣／美國／全球 |

每個分頁與子分頁最上方都有摘要（長度參考 RULES.md 6.1 的子分頁標準：4–6 句）；摘要分三層外觀，見 RULES.md 5.1。
